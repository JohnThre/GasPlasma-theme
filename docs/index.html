Gas Plasma

An orange-dominant theme inspired by ionized gas glow, in dark, light, auto, and color-blind-friendly variants. A single warm, high-contrast palette for Apple Terminal, iTerm2, VS Code, Open VSX-compatible editors, and Zed.

Releases Open VSX

Install Targets

Apple Terminal

Download GasPlasma.terminal (dark), GasPlasma-Light.terminal, or the GasPlasma-ColorBlind*.terminal profiles from GitHub Releases and open one in Terminal. Terminal profiles cannot follow the system appearance, so switch profiles manually.

open GasPlasma-Light.terminal

iTerm2

Import the dark, light, auto, or color-blind presets. For the auto presets, enable Use separate colors for light and dark mode first (iTerm2 3.5+).

GasPlasma-Auto.itermcolors

VS Code

Install from Open VSX, then pick Gas Plasma, Gas Plasma Light, or a Gas Plasma Color Blind variant. File icons switch with the theme; enable window.autoDetectColorScheme to follow the OS.

jpfchang.gas-plasma-theme

Zed

Install the color theme and file icon theme from the Zed extensions store. Both ship dark and light variants, plus the color-blind themes; set "mode": "system" to follow the OS.

Gas Plasma Theme + Icons

Color Blind Variants

Gas Plasma Color Blind and Gas Plasma Color Blind Light keep the orange background, text, and accent, but move every status signal off the red/green axis: additions, success, and strings are blue, deletions and errors are vermillion, warnings and modifications are yellow, and conflicts are pink.

  • Checked on every build by simulating protanopia, deuteranopia, and tritanopia (Machado et al. 2009) and requiring a visible OKLab difference between added/deleted, error/warning/success, ANSI red/green, and strings/keywords.
  • Status colors also keep at least 3:1 contrast against the editor background, and code colors keep 4.5:1.
  • The original Gas Plasma themes also separate added/deleted and error/success by brightness, so they stay readable with red-green color blindness.

VS Code Icons

File icons are generated from recognizable upstream language and ecosystem logo geometry where available. Product icons are generated from VS Code Codicons to preserve the original editor UI language.
